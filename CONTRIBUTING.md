# Guia de Contribuição

Obrigado por considerar contribuir para o Caminhos Altos! 🙏

## Como Contribuir

### 1. Fork o Repositório
Crie um fork do projeto em sua conta GitHub.

### 2. Crie uma Branch
```bash
git checkout -b feature/sua-feature
```

### 3. Faça suas Alterações
- Siga o style guide do projeto
- Adicione testes quando necessário
- Mantenha os commits claros e descritivos

### 4. Envie um Pull Request
Descreva suas mudanças e por que devem ser incluídas.

## Padrões de Código

- Use JavaScript/Node.js
- Siga o padrão de comentários do projeto
- Mantenha a legibilidade

## Reportar Issues

Se encontrar um bug ou tiver uma sugestão:
1. Verifique se já existe uma issue similar
2. Crie uma nova issue com descrição clara
